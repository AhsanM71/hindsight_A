# Asset credits

The owl, eye-drop bottle, slit lamp, picture chart, clinic garden, paths, materials and pictorial UI icons were created originally for this MVP using Unity geometry and project-authored C# drawing utilities. No downloaded artwork, AI art service, Asset Store purchase or paid API is used.

Unity's Universal 3D template, URP, Input System, uGUI and TextMeshPro are provided by Unity under their package licenses. Their license and notice files are included in the installed packages and package metadata.

The bundled TextMeshPro Essential Resources include Liberation Sans. Its font license and notice are imported alongside the font in `Assets/TextMesh Pro/Fonts/`. Those original notices are preserved.

The vision chart uses illustrative geometric pictures for navigation. It is not a visual-acuity test or calibrated chart.
