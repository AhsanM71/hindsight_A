# Storybook Journey Garden

The saved entry point is `Assets/EyeCanDo/Scenes/JourneyMap.unity`.

For the current presentation, use **EyeCanDo > Journey Map > Polish Journey Map (Iteration 2)** in Edit mode. Save any open scene changes first. This idempotent command adjusts the existing map and its three presentation prefabs, adds the gradient sky/clouds/hills, and preserves the environment and modal hierarchy. New materials, meshes, and the URP sky shader live in `Polish2`. The backdrop refits to the orthographic camera; nearby perimeter scenery may crop to keep destinations prominent.

The older **Author Storybook Garden** command re-authors the original garden and replaces manual geometry/presentation changes. It was not run for iteration 2. Do not use the whole MVP builder to update this map.

The catalog and JourneyDefinition assets remain unchanged. `JourneyMapLayout.authoredPlacements` maps stable IDs to map-only prefabs and local positions. Other catalog entries use their existing destination prefabs and receive automatic positions on a new row. `Rebuild()` makes curved paths and camera framing includes renderer bounds and world-canvas corners. The scenery's composition bounds and reserved viewport are editable on the layout. Future entries may also need authored terrain and planting for an intentional composition.

Equipment and badges both retain `JourneyDestination.Open()`. The map controller adds only `BackToStart()`, wired to the large arrow button. It uses the existing navigator and persistent AppRoot. Username persistence, Start routing, ButtonFeedback, and modal contents retain their existing behavior. Enlarged equipment, platform highlights, press feedback, and slow motion are presentation only. The fixed camera refits on aspect changes, with no camera motion animation.

Original equipment/architecture/terrain meshes are generated by `Editor/GardenGeometry.cs`. Materials, meshes, UI sprite, lighting profile, clinic prefab, and three destination prefabs are owned by this folder. Quaternius's 68 Standard-edition Unity FBX exports, textures, original CC0 license, source URL, and archive checksum are in `ThirdParty/Quaternius`. Nature uses project-owned URP Lit materials; foliage uses alpha clipping, not alpha blending.

Validation:

- **EyeCanDo > Journey Map > Validate Garden Assets** checks the loaded map, references, materials, catalog wiring, and automatic placement.
- The existing **EyeCanDo > Validation** commands check profile rules and the complete navigation flow. `PolishProfileProtection.Navigation()` wraps them in an additional disk-backed recovery record.
- In a running map with a saved username, add `GardenInteractionChecks` to a temporary GameObject to run the extra input/bounds checks. It removes its simulated devices, restores input settings, and destroys itself afterwards.
- Iteration 2 evidence is saved under `Validation/Polish2` outside Assets, including 1920x1080 and 1280x720 Game-view captures. Original garden evidence remains under `Validation/StorybookGarden`.
- `PolishProfileProtection.PrepareRestart()` backs up the exact existing PlayerPrefs username and saves the test name Alex. After restarting the Editor on Start, enter Play mode and add `PolishFlowChecks` to a temporary GameObject. It checks restart persistence and Back/Start routing, then returns to Edit mode and restores the original profile. These helpers are development-only. If interrupted, use **Restore Profile After Interrupted Polish Test** before ordinary play; never delete the pending recovery record manually.

No packages, shared art, catalog data, Start scene, JourneySelection scene, or capstone documentation are changed. Physical-device performance is not certified by Editor checks.
